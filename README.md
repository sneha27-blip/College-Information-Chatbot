# College Information Chatbot

## Project Overview
A web-based College Information Chatbot designed to help students get answers to frequently asked college-related questions.

## Technologies Used
- Python
- Flask
- NLTK (Natural Language Processing)
- HTML
- CSS
- JavaScript
- JSON
- SQLite

## Features
- Student Registration and Login
- NLP-based Question Matching
- 100+ College FAQ Questions
- Automated Chatbot Responses
- Chat History Management
- User Authentication
- Responsive User Interface

## Project Structure
- `app.py` – Flask application
- `chatbot.py` – Chatbot and NLP logic
- `database.py` – Database operations
- `questions.json` – FAQ dataset
- `templates/` – HTML pages
- `static/` – CSS and JavaScript

## How to Run

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Start the Flask application:

   `python app.py`

4. Open the local address displayed in the terminal in your browser.

## Purpose
This project demonstrates the use of Python, Flask, NLP and database management to develop an interactive college information assistant.
