# College Information Chatbot

## Project Overview
A web-based College Information Chatbot designed to help students get answers to frequently asked college-related questions.

## Technologies Used
- Python
- Flask
- NLTK
- HTML
- CSS
- JavaScript
- JSON
- SQLite

## Features
- Student Registration and Login
- NLP-based Question Matching
- 100+ College FAQ Questions
- Automated Chatbot Responses
- Chat History Management
- User Authentication
- Responsive User Interface

## How to Run

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open the local URL displayed in your terminal.

## Purpose
This project demonstrates the use of Python, Flask, NLP and database management to develop an interactive college information assistant.
